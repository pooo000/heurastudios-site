OpenAI stops new fine-tuning jobs on Jan 6, 2027 (developers.openai.com/api/docs/deprecations); this page is for the people who trained models there: what happens and when, a converter that turns their OpenAI training file (JSONL: chat, preference or the old prompt/completion format) into the Studio's question,answer CSV, in the browser (migrate.js: the file is never uploaded), and the three steps to train it in Heura Studios. The Studio's limits are the app's (studio/projects.py): 1,000 rows an import, 5,000 an AI, questions up to 2,000 characters, answers up to 4,000. {%- endcomment -%}

For teams who fine-tuned on OpenAI

Moving off OpenAI fine-tuning

OpenAI stops new fine-tuning jobs on January 6, 2027. Bring your training data to Heura Studios and keep training your own agent, without a machine learning specialist.

Convert your file Sign up
January 6, 2027
No new fine-tuning jobs on OpenAI, for anyone.
After that
Models you already fine-tuned keep answering until OpenAI retires the model they’re built on.
Your data
The training files you uploaded are still yours. Download them from OpenAI before you need them.

Source: OpenAI’s deprecations page.

Convert your training file

Drop in the .jsonl file you fine-tuned with. You get a question,answer CSV the Studio imports, and your system message to use as the agent’s script. The file never leaves your browser.

    Then train it in Heura Studios

    1. 1

      Make a notebook

      Sign up, choose New notebook and paste your system message into script.md. That’s where you say, in plain words, how the agent should behave.

    2. 2

      Import the CSV

      Open the examples tab and choose Import CSV. Up to 1,000 rows go in at a time, and an agent holds up to 5,000, so a bigger file comes out of the converter in parts.

    3. 3

      Test and train

      Add a few test questions with the answers you expect, then train. When the tests pass, run it by API or export it and run it on your own machine.

    How the formats map

    In your OpenAI fileIn Heura Studios
    The system messageThe agent’s script (script.md)
    A user messageThe question
    The assistant reply after itThe answer
    prompt and completionThe question and the answer
    preferred_output (DPO)The answer (the other one is left out)
    A reply with "weight": 0Left out, as OpenAI left it out of training
    Tool calls and imagesLeft out: the Studio trains on text

    A conversation with several turns becomes one row per reply, each with the question just before it. If a GPT model wrote your answers, check OpenAI’s terms before training another model on them: they limit using its output to build other models. The answers your own team wrote are yours to train on.
